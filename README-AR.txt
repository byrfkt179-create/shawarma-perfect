شاورما بيرفكت — نسخة Cloudflare Pages مع إرسال صورة الفاتورة تلقائياً
=================================================================

محتويات الحزمة
--------------
index.html
  ملف المنيو الأصلي بعد تحويل نقطة إرسال الفاتورة من Netlify إلى Cloudflare Pages.
  تم الإبقاء على تصميم المنيو والأصناف والأسعار ولوحة الإدارة وسلة الطلبات.

functions/api/send-order.js
  وظيفة Cloudflare Pages على المسار /api/send-order. تستقبل صورة الفاتورة PNG
  التي ينشئها الموقع، ترفعها إلى WhatsApp Cloud API، ثم ترسلها إلى رقم المطعم
  باستخدام قالب واتساب معتمد يحتوي على صورة في الترويسة.

طريقة النشر الموصى بها (Git integration)
----------------------------------------
1. فك ضغط الحزمة على جهازك.
2. أنشئ مستودع GitHub جديداً وارفع محتويات مجلد shawarma-cloudflare مباشرةً
   إلى جذر المستودع. يجب أن يكون index.html ومجلد functions في الجذر نفسه.
3. افتح https://dash.cloudflare.com/ ثم Workers & Pages > Create > Pages
   > Connect to Git، واختر المستودع.
4. اختر Framework preset: None.
5. اترك Build command فارغاً، واجعل Build output directory هو . (النقطة)
   أو جذر المشروع بحسب ما تعرضه شاشة إعداد Cloudflare.
6. انشر المشروع. لا تستخدم الرفع المباشر بالسحب والإفلات لهذه الحزمة؛ لأن
   Cloudflare Pages Functions تحتاج إلى نشر عبر Git أو Wrangler حتى تعمل.

إعداد أسرار واتساب في Cloudflare
--------------------------------
من Workers & Pages > مشروعك > Settings > Variables and Secrets، أضف القيم:

WA_ACCESS_TOKEN       = رمز وصول دائم/صالح من Meta WhatsApp Cloud API (Secret)
WA_PHONE_NUMBER_ID    = Phone Number ID لرقم الإرسال المفعّل في Cloud API
WA_RESTAURANT_TO      = 966505980900
WA_TEMPLATE_NAME      = new_order_invoice
WA_TEMPLATE_LANG      = ar
WA_API_VERSION        = v27.0

احفظ WA_ACCESS_TOKEN كـ Secret مشفّر، ولا تضعه داخل index.html أو GitHub.
بعد إضافة/تعديل المتغيرات أعد نشر المشروع إذا طلبت لوحة Cloudflare ذلك.

إعداد Meta WhatsApp Cloud API (مطلوب قبل وصول الفواتير)
------------------------------------------------------
1. فعّل WhatsApp Business Platform Cloud API في Meta Developers واربط رقم
   إرسال مخصصاً/مفعّلاً. رقم الإرسال الذي يعطيك Phone Number ID هو مصدر الرسائل.
2. رقم استقبال الطلبات هو 0505980900، ويكتب في الإعداد بصيغة دولية:
   966505980900. لا تضعه في WA_PHONE_NUMBER_ID.
3. أنشئ قالب رسالة Utility باللغة العربية بالاسم:
   new_order_invoice
4. اجعل Header من النوع Image، واجعل Body يحتوي متغيراً واحداً مثل:
   وصل طلب جديد إلى شاورما بيرفكت: {{1}}
   أرسل القالب للمراجعة وانتظر أن تصبح حالته Approved.
5. تأكد أن رقم المطعم 966505980900 يستطيع استقبال الرسائل من رقم Cloud API.

طريقة العمل بعد اكتمال الإعداد
------------------------------
العميل يضغط «إتمام الطلب» مرة واحدة. ينشئ المتصفح صورة الفاتورة ثم يرسلها
إلى /api/send-order. وظيفة Cloudflare ترفع الصورة إلى Meta وترسل قالب واتساب
إلى المطعم. لا تظهر قائمة مشاركة ولا يحتاج العميل لاختيار واتساب أو الضغط على
إرسال مرة أخرى. تعرض صفحة الطلب حالة النجاح أو رسالة الخطأ.

ملاحظات مهمة
------------
- ملفات الكود جاهزة، لكن الإرسال الفعلي لن يعمل حتى تضيف بيانات Meta الصحيحة
  ويكون قالب new_order_invoice معتمداً. لا يمكنني إنشاء رمز الوصول أو Phone
  Number ID أو اعتماد القالب نيابة عنك.
- لم يتم إرسال طلب تجريبي حقيقي؛ لأن مفاتيح Meta غير متوفرة.
- احتفظ برمز الوصول كـ Secret فقط، ولا تشاركه في المحادثات أو تضعه في HTML.
- رقم الاستقبال مضبوط افتراضياً على 966505980900 ويمكن تغييره عبر
  WA_RESTAURANT_TO من إعدادات المشروع.
